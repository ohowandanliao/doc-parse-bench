# 数据质量与合并结论

旧 129 篇和新标注可以在本项目中分别使用；目前不能直接拼接后计算同一个总分。新包实际有 81 份 PDF、597 页，并非 82 份。旧包有 129 份 PDF、372 页。

## 已确认的质量检查

新 GT 按人工整页快照覆盖链路结果：551 页 patch、46 页 chain，终态 8355 块。结构检查未发现空正文／标题／公式、零面积框或缺失标题层级；310 个 table 块均能解析为有行的 HTML 表格。147 条去重后的跨页链接，每条都至少在一个端点记录了 PASS；部分反向端点仍为 CHECK，不代表整条链接无人确认。

这些结果说明输入完整、格式可评测、跨页链接有确认记录，不等于逐字、逐数值重新人工验真。当前没有把自动结构检查描述成“全部内容质量合格”。

旧 GT 已抽核一份实际 PDF：`4-1统计图1.pdf`。图 1 的五年 GDP／增速表与原图标签相符；但是原本的统计图被转录成了数据表。该文档旧 GT 含 22 个表格，新 GT 对同一 PDF 标为 11 个真正 table 和 11 个 chart。这是任务定义偏向的直接证据，不能把 22 个表格的评分理解为纯粹的普通表格解析分。

旧 GT 的全部 129 篇没有经过本次重新逐项人工验真，因此不能断言它们与当前标注等质，也不能因为图表任务偏向就断言所有旧内容都低质。

旧包另含一份没有对应 PDF 的 `Handwriting document.md`，已移入 `data/legacy/unpaired_groundtruth/`，不参与 129 篇评测。两处重复存放的 129 篇 GT 在按文本读取后逐份一致，已统一为 `data/legacy/groundtruth/`；原数据目录保留指向它的相对链接。原压缩包仍保留原始内容。

## 已发现的重复

按 PDF SHA-256，以下两份完全相同：

| 旧集文件 | 新集文件 |
| --- | --- |
| `4-1统计图1.pdf` | `rd_5a681a57.pdf` |
| `2-3多层嵌套表头2.pdf` | `rd_6ebab0fd6715.pdf` |

两份合计 10 页。归一化正文的页面指纹也发现了这 10 页。直接拼接 129＋81 会至少重复计两份；按已确认的完全重复 PDF 去重后是 208 份／959 页，尚未排除扫描版或重新排版等近似重复。

## 推荐使用方式

| 数据范围 | 当前可以做什么 | 合并前还缺什么 |
| --- | --- | --- |
| 旧 129 篇 | 复现历史 Markdown 评测和 chart-table 任务 | 历史行的处理口径需逐条对应，不能假定全表同口径 |
| 新 81 份 | 官方 OmniDocBench 页面评测、MPDocBench 文档／跨页／标题树评测 | 继续积累内容复核证据，补齐失败模型推理 |
| 旧集普通正文／表格 | 可作为候选扩展数据 | 对照源 PDF 核验、补页面及块类型／坐标，统一表格和标题标准 |
| 旧集统计图 | 可作为独立图表数据提取任务 | 通用评测需重标为 chart，图表数据表单独确认和计分 |
| 旧集 MPDocBench 扩展 | PDF 可以重新标注后接入 | Markdown 无法恢复页面关系、图像框和跨页文本／续表 GT，需补标 |

先保留两个子集各自的成绩；统一标准后发布一份新的去重 manifest，保留原 GT 和历史分数。不跨文件名猜测“抽样部分”的原文连续性，不把旧分数与新分数直接做加权平均。

## 可重跑的审核

```bash
docbench audit-quality artifacts/prepared/baseline/gt_ir/documents artifacts/quality \
  --legacy-pdfs data/legacy/dataset/pdf/source \
  --current-pdfs data/annotations/sources
```

输出包括结构问题、没有 PASS 证据的关系、PDF 重复与正文页面重复。输出目录需为空。原始标注、PDF、模型输出作为本地数据保留，不随源码提交。
