# PDF2Text 模型替换评估：3.1-ft 与 3.1-origin

2026-11-20 的历史报告，记录 full282 基础解析和 129 结构／非空结果。11 月 25 日的正式内容评分见[实测与复算](legacy129.md)。

## 上线结论

**3.1-ft 可以先灰度替代 3.1-origin 处理普通 PDF，暂不建议全量替换。** 282 篇文档的 AgentBuilder-v2 从 77.90% 升到 78.46%，主要改善常规表格和阅读顺序。129 篇专项中，两版的附录和页眉页脚表现接近，ft 在 71 个标注图表中有 69 个实际转出了表格。

依赖**图内文字、精确图表数据、公式或跨页表格**的业务，建议先保留 origin，并用实际业务样本验收 ft。图片和印章的内容输出率是 ft 最明显的短板，其中有一部分分差来自合框和无字图片的描述，仍有带字线路图、流程图和设备标识确实漏转。本次是离线质量评测；灰度期间还需比较解析失败率、耗时和吞吐，保留回退能力。

## 四项功能怎么实现

在 PDF2Text `1806ec1` 的 MinerU3 路径中，四个开关可以通过 `/v1/pdfparse` 的 `parseConfig` 或同名表单字段传入。MinerU 先解析 PDF，返回页面、块类型和内容；PDF2Text 根据开关处理这些块，再渲染 Markdown。

| 开关 | 开启时 | 关闭时 |
| --- | --- | --- |
| 保留附录（`keep_appendix`） | 保留原有各页。 | PDF2Text 在文档后半段找首个以“附录”或 `Appendix` 开头的已识别标题，从该页起整页截掉。找不到符合条件的标题就保留全部页。 |
| 保留页眉页脚（`keep_header_footer`） | PDF2Text 把 MinerU 已识别的页眉、页脚和页码恢复到输出列表，统一按普通文本块渲染。 | 从输出列表移除带这些类型的块，包括页眉页脚图片。被模型识别成普通正文的页眉页脚不会被这条规则移除。 |
| 图片分析（`image_analysis`） | 启用 MinerU 的图块内容识别，保留返回的图内文字、图片描述等生成内容。 | PDF2Text 清除图片片段和标记为生成的片段中的文字，保留原图和普通图注。 |
| 图表分析（`chart_analysis`） | 启用同一套图块内容识别，保留 MinerU 从图表生成的表格数据。 | PDF2Text 将 `chart` 块改为普通图片，清空生成的表格内容，保留原图、图注和图表脚注。 |

**附录和页眉页脚不增加模型请求。** 它们的效果取决于 MinerU 是否识别对了标题和块类型。旧的 `seal_rec` 也能触发上游分析，但这版 PDF2Text 没有独立的印章过滤步骤，本次专项把印章纳入图片分析。

### 图片和图表的调用流程

**图片和图表共用一个任务提示词 `Image Analysis:`。** 以下模型内部流程以 MinerU 3.1.14 和其兼容的 `mineru-vl-utils` 0.2.7 默认实现为准。本次评测没有记录两台服务实际使用的提示词或逐图块的模型调用次数。

| 步骤 | 怎么调用 | 得到什么 |
| --- | --- | --- |
| 1. PDF2Text 提交 PDF | 图片或图表任一开关开启，就在同一次 MinerU `/file_parse` 请求里传 `image_analysis=true`。 | 一次解析任务，不计失败重试。 |
| 2. MinerU 检测版面 | 把整页图像和 `Layout Detection:` 提示词送入模型。 | 该页的区域框和初始块类型。 |
| 3. MinerU 分析图块 | 按区域框裁图，把符合条件的图片和图表裁块与 `Image Analysis:` 一起送入模型，可批量处理。 | 模型输出带标签的类别、图像说明和内容，例如图片文字、流程图代码或图表数据。 |
| 4. MinerU 组织结果 | 从模型的输出中读取 `class`、`caption`、`content` 等字段。 | `class=chart` 的结果按图表块返回；普通图片可返回图内文字或描述。它们与位置框一并写入 `middle_json`。 |
| 5. PDF2Text 过滤并渲染 | 按两个开关分别保留生成内容，再输出 Markdown。 | 只开图表时，上游仍做图块分析，PDF2Text 在输出前清除普通图片的生成内容。 |

一次服务请求内有版面检测和图块识别两个阶段，实际生成内容来自经过训练的模型。若版面阶段把两张图框在一起，内容识别收到的就是一张合框裁图。若 MinerU 最终返回的是普通图片，`chart_analysis` 不会把该框拆开或补转表格。

## 灰度验收

1. 普通文档先走小流量灰度，抽查基础解析质量，比较失败率、耗时和吞吐，保留 origin 回退。
2. 对含字线路图、流程图和设备标识，直接核对可读标签有没有转出。允许合框的业务可按内容验收，允许无字照片不生成描述；需要逐图定位的业务另查分框。
3. 对图表、公式和跨页表格，先验收双图混排、单位和数值、公式内容以及跨页关联。关键样本和线上指标通过后，再扩大替换范围。

| 图片：框对但文字没转出 | `5-1双栏表格2.pdf` / 2 | 抽取图内标签。核对 `CA/Solvent`、`Cutter`、`Extrusion Device`，ft **0/3**，origin **3/3**；流程图连线不在这个指标里。 |
| 图片：框有偏差但已转出部分文字 | `中山日报_深圳特区报合作_2.pdf` / 1 | 对第一张图核对两家报社名、事件和时间。ft **2/4**，origin **4/4**。同页其他图片或正文里的词不能替这张图得分。 |
| 图片：合框后有没有漏掉信息 | `依爱消防_电气火灾监控系统_5.pdf` / 1 | 两张接线图均有可读标注。合框允许，但一组标签不能同时给两幅独立图记分。若无法区分标签属于哪张图，单独记录归属不清。 |
| 图片反例：景物没字 | `广东城规院_惠玩甘青_7.pdf` / 1 | 盐湖照片无明确可读业务文字，抽取结果为空可通过。景物描述不计分；编造图内文字记错。 |
| 图表反例：地图有图例 | `成勘院_风能资源规划_10.pdf` / 1 | 保留主题地图，允许抽取图例；图例不得冒充该地图的数据系列。 |
| 图表边界：数据不能精确读出 | `5-1双栏表格3.pdf` / 6 | 散点图属于图表，但两轴范围不能当作散点数据。本页没有可靠点级真值，暂留诊断；有原始数据或预先标出可读值和容差后再进入数值评分。 |

| 能力 | 建议的主指标 | 保留的诊断 |
| --- | --- | --- |
| 图片转文字 | **关键文字召回**：在确实有可读文字的图中，核对预标的名称、型号、时间等。印章同法，单独报告完整章文；残章只在有可靠可读字段时纳入。另看错读或编造和无字图误出文字，不能靠多输出刷召回。 | 框匹配、拆框或合框、是否非空。描述和流程图连线另评。 |
| 图表转表格 | **正确数据项的精确率和召回率**：只在结构化表格中匹配“系列／类别或横轴值／数值／单位”。字段齐全的样本中，错列、错单位和错误数据不算命中，漏项扣召回，多报扣精确率。只允许事先写入标注的近似容差。 | 类型是否正确、框是否匹配、表能否解析；类别反例另外看误报。 |

先用同一个源 PDF 裁块、同一提示词对比两版，隔离内容识别能力；再用整份 PDF 检查实际交付，定位漏框、合框、类别和后处理问题。整页交付允许拆分或合并，但内容必须能归属到对应源图或数据系列，同一事实只计一次。现有 `content_output_recall` 和清除率继续用于开关回归。

这批已复核的难例用于调试；按文档及其版本分组，从未参与调参的常规样本和边界样本中留出一批，先定标签和通过条件，再做盲测。当前先修正上文统计图的类型候选，并补齐首批可核对的文字、数值、单位及反例预期；在这些口径稳定前，不把非空率或几个案例的试判合成 RSI 总分。

## 评测口径

### AgentBuilder-v2

总分为 **30% Omni 文本准确率 + 30% Omni 表格 TEDS + 30% Omni 阅读顺序准确率 + 10% TitleTree-v2**。表格 TEDS 衡量表格相似度；标题树先按完整文档评分，再对文档取平均。图内文字、图表数据和四项开关专项没有独立权重。

两个模型均走 PDF2Text `1806ec1` 的 MinerU3 路径。图片分析、图表分析和附录保留开启，页眉页脚保留关闭。标题层级重算开启，完整标题规则和 VLM 结构修复关闭。

### 四项能力

每个模型对 129 篇文档各解析两遍，获取带页码、类型和位置框的结构化输出（`middle_json`）。A 关闭 MinerU 的图片分析，B 开启；每模型 **258 次**，两版共 **516 次**。每组均覆盖 129 篇，复用 A 或 B，以相同的 PDF2Text 内容过滤器生成对照，专项不运行标题重算。

| 回放组 | 使用的推理结果 | 开启的功能，其余关闭 |
| --- | --- | --- |
| 全关基线 | A | 无 |
| 附录 | A | 附录保留 |
| 页眉页脚 | A | 页眉页脚保留 |
| 图片 | B | 图片分析 |
| 图表 | B | 图片分析、图表分析 |
| 图片关闭对照 | B | 无，用于比较同一次推理在过滤前后的图片内容 |

| 功能 | 计分规则 |
| --- | --- |
| 附录 | 以标注中位于文档后半段的首个“附录”或 `Appendix` 标题所在页为边界。比较打开和关闭时的附录召回、清除和正文保留。 |
| 页眉页脚 | 同页同类型一对一匹配，归一化文本相似度至少 0.85；页码作为独立类型统计。 |
| 图片和印章 | 同页一对一匹配，框的交并比（IoU）至少 0.5。印章纳入图片，排除由图表降级得到的图片。命中且至少有一项非空生成内容就计入；图片文字、印章文字、图示代码和描述均可计入。 |
| 图表 | 同页同为图表，IoU 至少 0.5，一对一匹配。命中且图表内容非空就计入；本批复核了计分输出确实为表格。关闭对照同时检查表格内容是否清除、图表是否降为图片。 |

召回率用命中数除以标注总数；精确率用命中数除以预测总数；内容输出率用命中且有内容的标注数除以标注总数；关闭清除率用成功清除数除以开启时已有的可清除输出数。合框诊断使用单独的预测框口径，正式分数仍按标注逐块匹配。

### 标注版本与内容限制

| 版本 | 提供的信息 |
| --- | --- |
| v1 | 旧 Markdown，部分图只有图片或图注，另一些统计图已转成数据表。例如，维修手册对应的旧 Markdown 保留了源图引用，但没转录图上的“音量调节”。 |
| v2 | 机标和人工复核后的结构标注，校正了标题，并提供视觉块的类型、页码和位置。 |
| v3 | 从 v2 的结构标注派生专项，当前使用 85 个图片、33 个印章和 73 个图表作为计分分母。v1 内容用于复核参考。 |

当前 v3 的 191 个视觉块没有逐块的文字或表格转录真值。**v1 没有转录，不代表源图没有文字。** 本次用 v3 的位置和类型确定分母，用模型预测判断是否实际产出；内容输出率不衡量字词或数值的正确性。需要评估转录准确率时，应给含字图片和图表补做逐块内容标注。
